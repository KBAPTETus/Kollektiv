# 🌾 Платформа «Kollektiv»

![Kollektiv Banner](public/assets/kollektiv_banner.jpg)

**Kollektiv** — это сверхлегковесная гиперлокальная цифровая доска объявлений и маркетплейс нишевых товаров (C2C) и услуг (B2C/C2C) для дачников, жителей СНТ, коттеджных посёлков и деревень.

<p align="center">
  <img src="public/assets/kollektiv_promo.jpg" alt="Kollektiv Mobile Concept" width="600" />
</p>

Проект решает проблему «заборных объявлений» и фанерных табличек на просёлочных дорогах («Продам навоз», «Откачка септиков», «Яйца, молоко»), оцифровывая локальное комьюнити без порога входа для пожилых людей.

---

## ⚡ Ключевые инженерные преимущества

1. **Функционирование в сети H+ / 3G / EDGE (Low-Bandwidth Budget)**:
   - Полный вес стартовой страницы (HTML + CSS + JS) составляет всего **~22 КБ** (< 8 КБ сжатия Brotli/Gzip).
   - Загружается быстрее 1.2 секунды даже при слабом мобильном интернете («одна палочка» связи в лесу).
2. **Offline-First Архитектура**:
   - `Service Worker` кэширует каркас приложения.
   - `LocalStorage` хранит каталог района — при потере сигнала экран не виснет, поиск и контакты доступны мгновенно.
   - Дельта-синхронизация запрашивает только изменения (`?since=...`), передавая всего 1–2 КБ по сети.
3. **Клиентское сжатие фото (Anti-Timeout)**:
   - Фотографии с камеры смартфона (4–8 МБ) сжимаются **на самом устройстве** через HTML5 Canvas перед отправкой в сеть до 800×600 WebP/JPEG (~35 КБ).
4. **Юридическая модель самозанятого (НПД)**:
   - Платформа работает как **информационный посредник (ст. 1253.1 ГК РФ)**.
   - Расчеты за товары/услуги идут напрямую между людьми.
   - Монетизация: официальная продажа рекламных услуг (бусты «В ТОП СНТ за 49 ₽») по ставке 4% без необходимости покупки онлайн-кассы (54-ФЗ).

## 🚀 Быстрый старт и запуск

### 1. Установка зависимостей
```bash
cd /home/kbaptetu/works/Kollektiv
npm install
```

### 2. Инициализация базы данных и тестовых объявлений
```bash
npm run seed
```

### 3. Запуск сервера разработки
```bash
npm start
# или с автоперезапуском при изменении файлов:
npm run dev
```

Сервер запустится по адресу: **`http://localhost:3000`**

## 📁 Структура проекта

```text
/home/kbaptetu/works/Kollektiv/
├── package.json          # Конфигурация проекта (Node.js ESM)
├── README.md             # Обзор и инструкция
├── ARCHITECTURE.md       # C4-модель, стек, оптимизация под H+
├── LEGAL.md              # Юридическая база и оферта самозанятого
├── server/
│   ├── app.js            # Express-сервер с Gzip/Brotli и умным кэшированием
│   ├── db.js             # Инициализация встроенной SQLite БД (WAL-режим)
│   ├── seed.js           # Начальные данные (СНТ Восход, Энергетик, яйца, септик)
│   └── routes/
│       ├── listings.js   # API объявлений (CRUD, дельта-синхронизация, бусты)
│       ├── locations.js  # API каталога локаций и категорий
│       └── upload.js     # Прием сжатых WebP фото
└── public/               # Ультралегковесный фронтенд (< 30 КБ общий вес)
    ├── index.html        # Семантическая мобильная верстка
    ├── styles.css        # Компактный CSS без тяжелых UI-библиотек
    ├── app.js            # Клиентский движок: кэш, Canvas-ресайз, фильтрация
    ├── sw.js             # Service Worker для работы в оффлайне
    └── manifest.json     # PWA манифест для установки на телефон
```

## 🛠️ API Спецификация

| Метод | Эндпоинт | Назначение |
| :--- | :--- | :--- |
| `GET` | `/api/listings` | Список объявлений (фильтры `type`, `location`, `category`, `search`, `since`) |
| `GET` | `/api/listings/:id` | Просмотр отдельного объявления |
| `POST` | `/api/listings` | Публикация нового объявления |
| `POST` | `/api/listings/:id/boost` | Оплата закрепления в ТОПе (буст на 7 дней) |
| `GET` | `/api/locations` | Список поселков и СНТ |
| `GET` | `/api/categories` | Список категорий товаров и услуг |
| `POST` | `/api/upload` | Загрузка сжатого WebP-изображения (до 100 КБ) |
| `GET` | `/api/health` | Проверка жизнеспособности сервера |
